# Crypto Dashboard - Frontend Boilerplate

This is a React + Tailwind frontend for the Crypto Investor Dashboard project.
It expects a backend API at `REACT_APP_API_URL` (see `.env.example`).

Quick start:
1. `npm install`
2. `npm start`

Files included:
- src/: React source code (App, pages, api client, context, routes)
- tailwind and postcss configs for TailwindCSS
